# Quick Start Guide

Welcome to **md2html**! This guide will get you started in under 5 minutes.

## Installation

```bash
pip install md2html
```

## Basic Usage

Convert a file:

```bash
md2html README.md
```

This creates `README.html` with beautiful styling.

## Options

- `--theme dark` - Use dark color scheme
- `--no-toc` - Skip table of contents
- `-o filename.html` - Custom output filename

## Example

```bash
md2html docs/*.md -d output/ --theme dark
```

That's it! Check the [full documentation](https://github.com/Crespo1301/MarkdownToHTML) for more details.
